# Push_swap

*This project has been created as part of the 42 curriculum by ilsyabri.*

## Description
The `push_swap` project sorts a stack of integers using two stacks and a limited set of operations.

## Instructions
Compile with `make` and run with `./push_swap 3 2 1`.
